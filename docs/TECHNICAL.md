## V2.7 分龄玩法与独立短片（2026-10-26，当前基准）

不以换色、换标题、随机版式或英语顺序排列宣称新玩法。56节创作课按目标选择实际工具；数理课采用十捆交换、十框、阵列、元角兑换、比例量杯、百分格、天平、变量记录等。开放任务只记录参与，不自动评判质量。3—6岁可用口述，输入收进大人可选记录。7岁起逐步加入听义、搭句，11—12岁加入听音补位。

200关均提供单独编写的三段拓展图解。短片换情境观察和迁移，不挂载本关编辑器，不读取或修改动手结果。原官方视频偏好保留；切换放入标题栏。图解是字幕与轻动画，没有新生成600段旁白。已完成任务可停留回看、重玩或继续。

完整逐关安排、年龄梯度与验证边界见 [200关分龄玩法与短片复核](200关分龄玩法与短片复核.md)。以下V2.6记录作为基础规范与历史说明。



## V2.6 统一交互规范（基础及历史）

全部200关通过同一课堂进入，旧课程链接映射到统一课堂，保留原课程ID、规则引擎、年龄顺序和学习记录。界面固定五个可点击环节；内部保留必要分镜，不再让孩子在多套导航间切换。故事自动衔接，动手与真实活动等待孩子。客观任务完成后自动反馈，错题保留操作并给出文字、视觉和语音支持；创作和口述只确认参与，不伪装为自动能力评价。

英语示范两遍，自愿录音、临时回放、鼓励，也可先听并继续，不按发音卡关。麦克风仅在点录音后请求权限，最长六秒；暂停、跳转和退出关闭采集并释放临时录音，不上传原音。原创/视频偏好独立于课程进度保存。

游戏逐关配置，语文与美术采用多种表达支架，分数采用覆盖纸片，比例采用方格房间，食物链采用连接箭头；棋类等保留原规则校验。英语交替采用听音、记忆、投递、配对、宾果、排序、路线和情境表达，不把换颜色算成新机制。完整安排见 games.html、docs/200关玩法安排.md 和 docs/UNIFIED-CLASSROOM.md。基础规则有意复用以支持迁移，不承诺200种互不相同的基础游戏规则。


## 架构

保留现有四十课引擎与资源，增加二百关路径入口和新的学科互动引擎。统一课堂映射兼容旧 ID；新路径记录规划 ID 与旧课 ID 的映射。新内容由课程源和具体任务配置构建，发布目录不携带构建运行时或模型。

课程数据、规则函数、界面渲染、声音播放与记录各自独立。规则模块使用纯函数，输入课程配置和任务状态，输出更新结果与具体反馈；界面不能自行伪造“答对”。棋规独立于剧情和落子动画。

## 数据与状态

课程主键为 P03-01 至 P12-20，具有 age、sequence、subject、concept、task、english、extension、existingCourseId 等元数据。新课进一步提供 interaction 与 lessonScript，已有课映射现存课件。

每关记录 stage、activityState、responses、english、artifact、observations、finished、updatedAt。应用级保存 selectedAge、cursorByAge 与版本。作品使用有上限的独立本机存储，文本和绘图可以导出。所有导入的数据仅按受限字段读取。

## 资源

沿用本地 SVG 角色与画面，按数量、图形、步骤、实验变量和棋盘状态生成可观察的变化。新演示使用原创分幕动作与实际旁白，不拉长时长。新增配音采用独立清单和内容 hash，先暂存、校验和备份，再按确认方案统一切换；生成可中断续跑。

官方视频仍由白名单元数据查找，点击才请求第三方，原始链接始终可见；待复核素材只在家长素材库中出现。离线和 file 来源保持本地教学可用。

## 发布与验证

以纯静态 HTML/CSS/JS 和 MP3 交付。规则使用 Node 内置测试，课程浏览和恢复使用 Playwright；发布目录检查文件引用、声音清单、数量与元数据一致性。GitHub 提交保留历史，不强制覆盖分支；Pages 构建完成后复核正式网址。

## 统一中文与保留英语

test/cherry-heart-release负责1014段中文的离线生成、校验和全量激活。参考为已确认的Cherry合成声音，GPT BF16、固定seed=2026；参考编码器在CPU，声学模型在GPU。母版去重、已确认试课复用和阶段性记录支持断点续跑。

787段Heart英语及两份英语JSON清单保持原始字节，通过文件SHA256与清单校验值验证。重建两份JS索引时只更新中文条目，英语元数据原样沿用。中文文件名含声音配置hash，HTML索引缓存版本同步更新。

清空旧的单关声音覆盖，所有课程读取各自统一清单。经典引擎预加载、实际播放和静音自动推进都读取当前音频元数据；英语额外慢放由locale判断，不能拖慢中文。原存储键、课程ID、教学数据与内容版本不改变。

激活前校验全部中文、备份旧文件和清单，激活后移出未引用旧中文与旧试课MP3。失败恢复旧清单和文件；模型与备份不进入code。发布采用精确同步，包括删除已替换旧文件，校验暂存Git树与远程树一致后非强制更新引用。
