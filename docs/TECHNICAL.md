# 二百关课堂技术设计

版本：V2.3 · 2026-10-25。

## 架构

保留现有四十课引擎与资源，增加二百关路径入口和新的学科互动引擎。旧课堂以独立页面兼容旧 ID；新路径记录规划 ID 与旧课 ID 的映射。新内容由课程源和具体任务配置构建，发布目录不携带构建运行时或模型。

课程数据、规则函数、界面渲染、声音播放与记录各自独立。规则模块使用纯函数，输入课程配置和任务状态，输出更新结果与具体反馈；界面不能自行伪造“答对”。棋规独立于剧情和落子动画。

## 数据与状态

课程主键为 P03-01 至 P12-20，具有 age、sequence、subject、concept、task、english、extension、existingCourseId 等元数据。新课进一步提供 interaction 与 lessonScript，已有课映射现存课件。

每关记录 stage、activityState、responses、english、artifact、observations、finished、updatedAt。应用级保存 selectedAge、cursorByAge 与版本。作品使用有上限的独立本机存储，文本和绘图可以导出。所有导入的数据仅按受限字段读取。

## 资源

沿用本地 SVG 角色与画面，按数量、图形、步骤、实验变量和棋盘状态生成可观察的变化。新演示使用原创分幕动作与实际旁白，不拉长时长。新增配音采用独立清单和内容 hash，避免更改已确认资源；生成可中断续跑。

官方视频仍由白名单元数据查找，点击才请求第三方，原始链接始终可见；待复核素材只在家长素材库中出现。离线和 file 来源保持本地教学可用。

## 发布与验证

以纯静态 HTML/CSS/JS 和 MP3 交付。规则使用 Node 内置测试，课程浏览和恢复使用 Playwright；发布目录检查文件引用、声音清单、数量与元数据一致性。GitHub 提交保留历史，不强制覆盖分支；Pages 构建完成后复核正式网址。
