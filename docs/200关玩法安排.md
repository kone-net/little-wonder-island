# 200关分龄玩法与短片复核（experience-v1）

## 原因与调整

旧版56节创作课以序号轮换画板、文字框和装饰性版式；英语靠七种基础任务重排；短片又复用了任务说明。此前“配置数 / 顺序组合数”不能证明孩子实际玩到了不同游戏。

课程配置标签不等于独立游戏机制。共享工具与规则仍然复用，但按目标选择可观察的操作：拼搭、叙事卡、真实动作记录、单元复制、声音编曲、口型、部件观察、空间规划、角色交换、资料比较、规则实验、预算、方案取舍和写作证据板；数学另有十捆、凑十、阵列、元角、比例、百分格、天平、变量表等。棋类继续使用各自合法规则。

## 年龄递进

- 3岁：单一步骤、明显图像；点选与模仿，不要求识字。
- 4岁：两步操作、简单分类与角色轮流；口述可代替输入。
- 5岁：同时看两条线索、简单计划与对照；允许调整。
- 6岁：多步指令、规则复核和迁移；加入自己设计。
- 7岁：具体材料解释数量与因果；做完说明一种方法。
- 8岁：比较两种方法，区分步骤和条件。
- 9岁：给出依据，区分观察与推测，检查单位。
- 10岁：控制条件、表示关系，并比较方案限制。
- 11岁：多次记录、反例、来源与预算约束。
- 12岁：多变量取舍、证据链与验收；说明不确定性。

## 环节职责

- 问题与方法：建立概念；沿用原中文声音。
- 动手：由孩子操作、解释、创作或记录；数理与棋类依规则核对，创作口述只记参与，不冒充能力评测。
- 短片：200份单独撰写的三段拓展图解，换例子看迁移，不挂载当前游戏、画板或表单，不读取或改动孩子的操作。可选官方视频与偏好继续保留。新图解为字幕和轻动画，未新生成600段故事配音。
- 英语：3—6岁重物品与听辨；7岁起加入听信息选意思、听句搭建；11—12岁加入听音补位。仍读两遍，中文释义与自愿录音保留。
- 回顾：把发现带到真实生活。
