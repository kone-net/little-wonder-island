# 小小奇遇岛：动物奖励与小屋设计调研

版本：reward-play-v1，2026-10-28。本文件记录已核实的同类产品做法、设计依据和本次实现；逐关课程仍以 [PRD](PRD.md) 为准，技术边界见 [TECHNICAL](TECHNICAL.md)。

## 1. 调研结论

### 1.1 孩子“奖励动物、放进房间”可能见过什么

最接近的已核实案例是 Khan Academy Kids。其官方介绍明确写到：五个动物角色引导阅读、数学等学习，孩子完成学习后收集虫子、帽子、玩具和衣物，收藏放在角色房间里。官方家长指南进一步描述了每个房间都能玩的不同内容，如给大象玩洗澡玩具、看小熊猫虫子收藏、给小鸟换装、玩澳洲野犬的乐器、给熊换帽子。这提供了一个明确模式：**学习路径有连续性；奖励回到空间后仍可互动；每种角色有自己的玩耍方式。**

- [Khan Academy Kids 官方角色与收藏介绍](https://khankids.zendesk.com/hc/en-us/articles/360049358751-Learn-more-about-the-characters-inside-Khan-Academy-Kids)
- [Khan Academy Kids 官方家长指南：房间与玩具](https://khankids.zendesk.com/hc/en-us/articles/360006764812-Parent-and-Home-Account-Users-Getting-Started-and-creating-an-account-with-Khan-Academy-Kids)
- [Khan Academy Kids 官方学习进度说明](https://khankids.zendesk.com/hc/en-us/articles/360041615571-How-does-the-learning-level-adjust-and-how-do-I-view-my-child-s-progress)：官方奖品会间歇出现，并与完成及准确性有关。这是其现行规则，不作为本项目需要照搬的条件。

### 1.2 奖励为什么不宜只做积分

一项针对 67 名 9—13 岁儿童的虚拟狗与体力活动研究发现，单独给积分只短暂增加参与，总活动量没有显著提升；孩子会调整行为来更容易拿分。它研究的是体力活动，不足以证明课堂中的动物奖励有效或无效，但提醒我们：别把“刷分”变成学习目的。[研究原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6566098/)

美国儿科学会的儿童数字媒体说明特别指出，自动播放、无尽滚动和让孩子不断玩的奖励设计会挤占睡眠、现实游戏与亲子互动。因此本项目的小屋定位为**有限、能随时离开的短暂自由玩耍**：没有饥饿值、宠物死亡、签到连胜、随机盲盒、广告或付费道具，也不会要求再学一关才让动物“舒服”。[AAP 说明](https://www.healthychildren.org/English/family-life/Media/Pages/helping-kids-thrive-in-a-digital-world-AAP-policy-explained.aspx)

### 1.3 对小小奇遇岛的推论

Khan 的角色房间证明“奖励后能回去玩”的形态已被成熟儿童教育产品采用；研究和儿科建议提示奖励应让孩子产生选择、陪伴和表达，而不是只追逐数字。这是基于上述来源的**设计推论**，不是对本项目学习效果已经验证的宣称。

### 1.5 对本项目的调整决定

奖励小屋需要从“布置界面”改为“有四个可点进入的游戏角”，而动物不是统一的二选一问答。每次进入先看到大场景，再点一个动物或游戏角；每个角只有一个显眼主动作，结果立刻在画面里发生。拖动摆放保留为自由装饰，不作为主要玩法。

|游戏角|孩子的动作与画面反馈|关联课程|低龄简化与高龄扩展|
|---|---|---|---|
|照顾角|点水盆、毛巾或食物，动物喝水、擦干、闻一闻；随后孩子选一个自然动作继续故事|生活习惯、动物观察、简单语词|3—4岁一次点一个图；5—6岁按两步顺序；7岁以上可写/说观察结果|
|搭建角|点大块道路拼出两三段路线，动物沿路跑到目的地；可随时改路线|空间方位、形状、规律、简单规划|低龄每次只选下一块，自动吸附；高龄可选择两条路线比较|
|声音角|点鼓、铃或叶子听音，动物随节奏摇摆；自己敲一段并回放|音乐节奏、听辨、英语词音|低龄自由敲，无输赢；高龄可模仿短节奏，允许重试|
|故事角|选一位伙伴、一个场景、一件事，画面组合成一张小故事卡；可讲给家人听|语文表达、认字、英语句型|低龄只选图说一词；高龄延展成完整句或前后情节，不做自动口语评分|

动物身份进一步决定互动细节：小鸟在声音角唱、松鼠在搭建角藏果子、小狗在故事角寻物、小象在照顾角用鼻子浇水。一个游戏角可以容纳多种动物，但反馈和目标随动物改变，避免“换动物皮肤，题还是同一道”。家具也应有用途：故事书开启故事角，乐器开声音角，地毯成为表演舞台，盆栽成为照顾角的浇水对象。每关奖励仍是确定的，不靠随机抽奖。

**先做能验证的纵向切片**：4岁第1关给小兔和野餐道具；通关后能在小屋给小兔准备点心、在两块大图中搭去野餐垫的路、听它的短反应，再生成一张“我和小兔去野餐”的故事卡。此切片在 iPad 上应能由3—6岁孩子不识字独立完成主要动作。验证后扩展到其他动物和关卡；不能把只有摆放与二选一的本地原型作为完成版发布。

### 1.6 节奏与边界

课后弹出奖品只给两个去向：`去小屋玩一会儿`、`接着学/今天先休息`。小屋不弹连续任务，不要求再上一关才能照顾动物；动物没有饥饿、疾病倒计时、死亡、签到连胜或付费。一次互动约1—3分钟，可以随时离开，返回仍默认续上次课程。家长可在小屋打开简单的“今天玩了什么”卡片，连接线下说故事、画画和真实观察。设计依据是 [AAP 对延长使用的奖励、自动播放和无限滚动的提醒](https://www.healthychildren.org/English/family-life/Media/Pages/helping-kids-thrive-in-a-digital-world-AAP-policy-explained.aspx)，具体时长是本项目的设计目标而非医学阈值。

## 2. reward-play-v1 实现规格

### 2.1 入口、奖励与收藏

首页新增“我的小屋”，课堂结束展示本关礼物和“带它去小屋”。room.html 可以直接打开，无学习记录时也有常驻小兔，四种玩法立即可用；常驻伙伴不伪造关卡完成、不占通关礼物。小屋顶部有“回到课堂”“故事相册”“布置小屋”“我的收藏”。

每关走到结尾，且动手挑战有正确完成/明确参与记录，得到一件固定礼物。记录只表示实际参与，不宣称掌握；视频可播、录音、识字和离屏实践不成为领取条件。每龄01、06、11、16关为动物，其余关为盆栽、地毯、星灯和故事书。200关合计40个动物伙伴实例、160件物品，动物实例分为10种物种；不同课程可能得到相同物种，并非40个独立物种。4岁第1关为小兔。

稳定课程ID决定奖品，每关只领取一次。旧合格完成记录进入小屋时补发；重玩、刷新、阶段重置不会收走奖品或重复发放。收藏中点卡片自动入住；房间最多展示5只动物、8件物品。布置模式支持拖动换位置、单击收回；常规模式点动物只切换玩伴，避免孩子无意收回动物。动物包括兔、狐狸、熊、猫、大熊猫、鹿、狗、松鼠、鸟和象；物种具有相应的耳朵/尾巴/羽毛/象鼻等本地SVG特征。

### 2.2 四种实际玩法

|游戏角|画面与操作|实际反馈/完成|保存与退出|
|---|---|---|---|
|照顾伙伴|大动物图和喝水、梳毛、点心三个大图按钮；鸟改为理羽毛，点心随动物变化|点按钮立即发生低头、摇动、咀嚼等短动作；工具出现尝试标记；文案如“小兔低下头，咕嘟咕嘟喝水啦。”；没有必须完成的三步任务|记住所选动物尝试过的工具，退出立即停止动画|
|搭一条路|3×5大格子，起点动物、终点小屋；单击放路块，再点可收回。3—4岁可直接连路，5岁以上中央有不可通行水塘|只接受上下左右连通，BFS检查可达路径；铺通后自动出发，动物沿路逐格移动。未连通点“出发”提示“还有一段没有连上。点相邻的空格，把路接到小屋吧。”；成功提示“这是你搭的路”|每只动物分别保留路块；“重新搭”只清本动物的道路。关闭或切后台停止演示，不影响课程|
|森林音乐会|四个不同颜色/形状的大音符键；每点一个产生一个本地合成音，同时动物摇摆、色块加入旋律带|最多16个音，点击“听我的旋律”按当前序列回放；回放期间不能同时录入；“再编一段”清空旋律。是音符序列创作，并非对孩子演奏节奏的精确录音|保存最近一段音符序列；关闭、切后台立即停止振荡器和回放计时器；iOS声音由点音符的手势触发|
|我的小故事|点花园/海边/星空图片，再点分享点心/音乐会/找宝藏图片；画面同步改变地点、道具和句子|例如“小兔在星空下开音乐会。”；孩子可讲一词或一段，不要求麦克风，不做口述质量评分；“保存我的故事”收入相册|最近12种图画组合，重复保存同组合不复制；相册可反复打开。当前保存图片组合及示例句，不保存孩子原声或自编台词|

四个角不是四套二选一题，而是即时照顾反馈、空间连通与模拟、声音序列创作、图画故事组合四种规则。不同动物共享这些规则，同时改变角色造型、点心、称呼和照顾细节。本次未实现每种动物一套完全独立游戏，也未宣称7—12岁已有专属完整深度玩法。

### 2.3 视觉与平板交互

暖白页面、森林绿按钮、木色地板、窗户/沙发/挂画/书架和可选择的动物构成原生矢量小屋。四个玩法使用大图入口，点开后是有明显关闭按钮的单一活动画面。iPad横屏四个入口横排，竖屏/手机按空间换行；所有活动保留至少44px的实际操作目标。模态框上限取动态视口高度，过小窗口允许自然滚动，不裁掉提示或按钮。

主小屋与课堂奖励样式分文件，课堂不加载room.css，避免小屋body/button全局样式改变课堂。原有课程音色、200关内容和节点数量均未改变；小屋新增声音仅为本地合成的音乐音效，不使用浏览器临时TTS冒充既定音色。

### 2.4 确定的边界

可以随时离开，没有饥饿/死亡、签到、盲盒、付费和排行榜。自由玩不产生额外奖品。当前同一浏览器只有一个小屋；保存失败会显示提示。换设备由家长使用既有导出/导入记录迁移；没有自动云同步。当前家具是可摆放收藏，尚未按家具分别触发专属动作；路线难度分3—4岁/5岁以上两档，故事与音乐为全龄开放创作工具。后续深度应建立在真实儿童的iPad试玩反馈上。

## 3. 技术与验收

独立room.html加载assets/island-rewards.js、room-art.js、room.js和room.css；课堂只加载island-rewards.js及island-rewards.css。仍使用little-wonder-island-academy-v3，新增rewards={version:1,earned,placements,roomPlay}；roomPlay存care、routes、music、stories，奖励ID是课程ID。写入前读取最新课程记录，仅合并小屋数据，避免打开课堂和小屋两个标签时小屋覆盖课堂的新进度。家长导入验证课程ID、位置、音符范围和故事组合，不清除既有记录。

验证包含200关礼物映射、40动物/160物件、重复授奖幂等、跳过主挑战不授奖、旧记录补发、课堂结尾礼物入口、常驻伙伴、照顾按钮反馈、道路失败/连通/绕水塘、音乐输入与回放、故事去重与刷新恢复、收藏入住/布置拖动/收回、不同视口与模态框溢出、关闭与后台停止。截图和脚本位于release/v2/test/reward-room；它们不会作为生产依赖发布。浏览器模拟触控不能替代真机iPad及儿童观察测试。


## 农场增量 farm-life-v1（2026-10-28）

room.html现为开放农场，替换室内背景。默认常驻小兔、小狐狸、小鸟，不伪造通关；可同时加入最多12只通关动物和8件物品。所有动物（包括常驻伙伴）默认直接拖动，无需先开启布置模式；拖动保留抓取偏移，落点按百分比保存，放下后20秒不自主走动，防止误以为没放好。布置模式的单击收回仅针对已获奖品，常驻伙伴保留。

农场“喂动物”按钮切换喂食模式，单击任意动物给予对应点心，出现食物、爱心和咀嚼动画；拖动仍可用，不将拖动误判为喂食。伙伴在前台空闲时每3.2秒抽取一只短距离散步，并有错开时序的呼吸、眨眼和鸟类轻摇动作；进入活动、切后台或拖动时暂停自主散步。尊重减少动态效果设置。当前是原生SVG与CSS动画，不是物理模拟或逐帧骨骼动画。

常驻位置存于rewards.roomPlay.residents，通关位置仍是placements；旧记录保留。家长导入应包含三位常驻位置，字段仅接受预设伙伴ID和有限坐标。四个原有活动保持可用。验证直接拖动常驻伙伴/刷新落点、7只动物同时展示、点喂食、平板横竖屏和旧照顾活动。
