# 小小奇遇岛 PRD：3—12 岁二百关融合课堂

版本：V2.3 · 2026-10-25。依据已确认的《3—12岁整体课程方案》进入实施。

## 1. 产品目标与范围

面向家庭使用的中文主导融合课堂，3—12 岁每龄 20 关，共 200 关。每次约二十分钟活动量，把明确教学、可操作游戏、英语、欣赏、动手与表达放进同一任务。语数外是主线，艺术、音乐、科学、运动、劳动、文化、信息和棋类交替出现。

沿用四十个已有课题与已确认的声音，新增一百六十个不同内容的课题。年龄用于选择起点；英语基础和孩子的表达方式可以独立调整。本版本是每龄首批二十关，不承诺覆盖全年教材。

发布代码仍位于 `code`，构建、自动检查、配音母版位于 `test`，PRD 和课程文档位于 V2 根目录。生产不依赖 Python、模型、密钥、登录或后端。现有四十课需继续可用，旧链接和旧进度有明确入口。

## 2. 核心用户路径

首次打开 → 选择年龄 → 查看本龄第一关 → 准备材料 → 开始。以后默认显示“继续上次”，不要求重新选课；家长可以展开二十关目录、按科目筛选、换年龄或回看。十个年龄的进度独立。

课堂顺序：故事问题 → 看见概念与具体例子 → 主任务与纠错 → 原创演示／可选官方短片 → 英语听说 → 离屏迁移／作品 → 回顾与结局。允许主动继续、暂停、重做和暂缓离屏活动，不强迫坐满计时。

较低龄以图、口述、动作与少量按钮完成；较高龄加入表格、句段、图示、方案与解释。所有关键操作支持点选和键盘；画板支持触屏。写作不强制键入长文，可先选句段或口述后记录。

## 3. 每关内容合同

每关包含稳定 ID、年龄、路径序号、科目、标题、主要概念、概念解释、具体例子、故事问题、示范、可执行任务、提示、判定或观察方式、英语目标、迁移任务、结局和资源来源。题目数据必须具体：实际数量、棋子位置、文本、选项、序列或实验参数不可缺。

游戏中必须体现概念。例如分数比较保持同一整体，比例写清对应数量，统计图说明刻度，象棋行动由规则判定。不能把“看过文字”算作完成实际操作，也不能仅更换标题就称新增一课。

数理、路线、排序、分类、棋局等闭合任务使用确定规则反馈。创作、写话、真实观察、运动与讨论采用作品或陪伴者确认，不声称系统理解了文章、诊断健康或自动打了口语分。

## 4. 互动能力

| 类型 | 必须支持 | 判定边界 |
|---|---|---|
| 数量与模型 | 操作数值、分组、单位份或刻度；可重试 | 根据明确目标与当前状态判定 |
| 分类与对应 | 看对象后选择类别或配对，保留中间状态 | 每个对象实际归位才完成 |
| 顺序与指令 | 重排具体步骤，检查遗漏和因果 | 不用完全无关的固定选项代替 |
| 实验与数据 | 改一个条件、记录至少两种情境、比较结果 | 模拟明确标为模型；真实记录允许不同结果 |
| 路线与程序 | 障碍、位置、有限指令、重置和调试 | 逐步执行，不穿障碍或越界 |
| 画板与写作 | 画笔、颜色、撤销、保存作品或文字 | 不用笔画数、字数当创意质量分 |
| 音乐与动作 | 节奏示范、逐拍输入或跟做确认 | 不偷偷启用麦克风或摄像头 |
| 棋类 | 轮流、连线、合法走法、局部目标、提示和重置 | 不随机落子充当合格对手；残局先验合法性 |

同一引擎可以复用，但每关要有自己的材料、数值、任务和迁移目标。围绕对象的显著变化和提示必须与操作同步；错误保留可修正，成功后不能继续重复计数。

## 5. 棋类规则

共二十个棋类主题，低龄准备游戏与正式棋种分开标明。五子棋采用本版明确说明的儿童自由连五规则，不设禁手；检查横、竖、两条斜线，落子不得覆盖已有棋子。三连棋使用三乘三与三连规则。

象棋从车、马、炮的局部规则走向将帅与合法小残局。引擎至少覆盖棋盘边界、己方占位、车路阻挡、马腿、炮架、象眼与不过河、士将九宫、兵卒过河前后方向、将帅照面和自陷被将。不以“把将吃掉”的动画跳过应将规则。界面说明当前是规则练习还是残局，不把局部练习盘称作完整对弈人工智能。

## 6. 英语与声音

继续使用用户确认的 CosyVoice3 候选 3 中文参考，英语 Heart 女声与慢速。新增内容导出实际 MP3 与文本清单，不依赖浏览器机器音临时冒充已确认音色。听词句支持三遍示范、单次重放、额外慢放、物品／语境对应和无答案提示的听辨。较高龄通过句型支架和换情境运用提升表达。

配音中英文分开生成。播放不阻塞操作；暂停、切课、返回和隐藏页面时停止声音。没有人工完成全部听审时，验收记录要区分文件与文本检查、抽样试听和人工声音确认。

## 7. 影片与演示

每关至少有与本课材料相关的本地原创可播放演示，保留无网络可用的教学路径。已有官方配片继续按需播放；新增课只有经过匹配与实际起播检查的外部视频才可设为默认。不得将五百条未完整复核的候选随机分配成二百关默认影片。

原创演示显示实际片长或播放进度，允许暂停与重播。它与一整集商业动画不同，应如实命名。超出预算的外部原片作为课后拓展，不截断结局、不循环凑二十分钟。外部播放器沿用真实 origin 与 Referer、本地文件打开 HTTPS 播放页的修复。

## 8. 记录、迁移与隐私

本机保存当前年龄、每龄续关、各关环节状态、可恢复的任务状态、作品和家长观察。读写 localStorage 失败时显示提示并保持当次可用；作品过大时限制数量或提示导出，不能无声丢失。

现有四十课保持原 ID、音频和数据；新路径通过映射读取完成情况，不清空旧数据。允许导出与导入本机学习记录，导入前校验版本、ID 和容量，不执行导入文本。清空需要确认且只清本应用数据。

无需麦克风、摄像头、孩子真实姓名、云账号或公开作品上传。不主动发送家长或孩子的信息。计时仅表示本机活动时间，不声称注意力、智力或掌握程度。

## 9. 年龄与时间

按已确认方案的四类二十分钟活动预算实施。年龄只影响内容、信息量与表达支架，不限制家长自由回看。学前以生活和游戏为主；正式语数外按在读进度调整。长实验只在当堂完成设计或读记录，实际生长与蒸发后续记录，不模拟成“当场真实发生”。

## 10. 验收与交付

1. 数据审计：十龄各二十关，稳定 ID 唯一，四十条旧课映射不变；每条有具体可执行内容。
2. 交互：逐关加载与完成路径可测试；错误、重置、暂停、切换、刷新恢复可测试；作品明确按创作确认完成。
3. 棋规：覆盖边界、占位、阻挡、腿眼、炮架、九宫、过河与王对王规则；所有残局自动复核。
4. 声音：实际文件存在、非零时长、文本和 hash 对应，中文参考身份与英语速度不变。
5. 布局：手机、桌面、键盘与减弱动效可用，无横向溢出和遮挡主要按钮。
6. 兼容：原四十课链接、影片、配音、英语重复、旧进度仍可使用。
7. 发布：可独立部署的 `code`、一致的压缩包、PRD、技术设计、课程目录与验收记录；既有 GitHub Pages 更新后检查实际网址。

完成状态以验收事实记录；不得用目录页可见冒充课程、语音或视频制作完成。
