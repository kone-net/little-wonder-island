# 200关统一交互版

2026-10-26 修正见 [教学画面与英语交互修正](CONTENT-FIXES-20261026.md)：分龄教学、完整盖牌、图形尺寸、视频入口、配对选中与连线；缓存版本 all200-v3。

本次将已确认的森林野餐样板交互推广到 3—12 岁全部 200 关。主入口为 `index.html`，课堂为 `classroom.html#P年龄-关卡`，玩法总览为 `games.html`。

## 共同体验

- 首页顺序续关，固定五个可点击环节：问题/故事、动手、短片、英语、生活与回顾。学科内容和活动强度按年龄调整。
- 中文故事和讲解自然衔接；关键操作等待孩子。客观任务按原学科规则判断，错误保留操作，清楚显示具体提示并提供语音和示范入口；完成后自动反馈与衔接。
- 单词与句子均示范两遍，自愿录音、回放与鼓励；可先听而不录，不按发音、音量或录音时长判定正确。
- 同一浏览器记住原创/视频偏好。已配课官方视频仍保留；没有年龄与主题适配片源的新增课程采用原创方法演示，不虚构商业动画或视频链接。方法短片按实际内容呈现，不循环凑20分钟。
- 原中文 Cherry 克隆、英文 Heart 音色及既有音频文件保持不变。新增九条英语玩法指令继续使用本地 Heart、0.78 语速。

## 游戏差异

逐关安排见 [200关玩法安排](200关玩法安排.md) 和 `games.html`。保持学科规则正确，不把同一题换标题当作新游戏。

- 学科任务根据内容采用数量操作、纸片覆盖、方格设计、归类、顺序重排、食物链连接、条件实验、路线、节奏、电路、编程、排错、棋形，以及故事图卡、四格表达、证据板、海报、拼贴、对称绘画等配置。
- 同龄相邻关卡避免相同的主要任务配置；相同基础规则允许在不同问题中迁移。例如分数采用覆盖纸片，比例采用方格房间边界，食物链采用方向连接。
- 英语以听音寻宝、翻牌记忆、情境投递、声音配对、宾果、声音/句子排序、路线送信为基础，另有情境表达及图片回忆/句子补位。每关安排三个不同任务，顺序按课题分配。单句课程与幼儿课程采用相应支架，不强迫识字或脱稿表达。
- 开放创作、真实活动和口述由孩子或陪伴者确认参与，系统不评判作品优劣或文章语义。示范不会直接计作孩子完成的作品；先看方法可以继续，但记录为暂缓/观看。

## 技术与兼容

- 保留原两套课程数据与游戏规则引擎，通过统一课堂控制器和纯视图适配器接入，避免重写棋类与数学规则。
- `classroom-plan.js` 保存200关配置；`classroom-views.js` 从原已验证的任务视图生成；生成入口为 `test/build-classroom.js`。新交互状态保存在原课程记录的 `flow` 字段，不修改关卡ID或原学习记录键。
- 主入口与旧课程书签均进入统一课堂；原年龄顺序、完成记录、已有游戏操作和作品保留。导入导出继续携带统一课堂进度。
- 暂停冻结语音、等待和动画；切换环节取消旧任务、关闭外部播放器和麦克风。声音未能自动启动时显示显式启动按钮，加载失败可重试。
- 录音模块仅在主动点录音后请求权限，最长六秒；Blob仅在内存回放。暂停、跳转、退出释放媒体轨道与临时URL，不上传、不写入学习记录。
