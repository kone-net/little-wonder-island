# 教学画面与英语交互修正（all200-v3）

补充版本 all200-v4：200关的全部467次英语示范配置均提供中文释义；单词卡和句子示范下方展示对应意思，继续使用原英语配音。翻牌时中文和图片一起隐藏。

160节新增课的原创短片不再挂载游戏、画板或表单，改为独立的三段图解播放；5岁第14关使用纸张、船身旗帜、装饰设计的龙舟动画。其他未配片的新增课使用各自教案三段图解，属于轻量图解短片，未冒充外部动画或新增完整配音。支持“看好了，继续”，不改变孩子的动手记录。`film-meanings.js` 检查480段只读图解和所有英语示范释义；`check-memory-meanings.js` 检查新中文释义不会从卡背透出。

## 问题与修正

- 统一课堂此前漏加载 `age-scenes.js`，30节3、5、6岁旧课程退回四岁模板。显式加载分龄渲染器；另以 `classroom-scenes.js` 按课程数据修正分享对象和数量、双条件筛选、重复单位、购物代币及浮沉对照画面。缺少分龄模块时显示加载提示，禁止静默使用错误年龄模板。
- 三等分按6份、3人、每人2份呈现，四等分按8份、4人、每人2份呈现。分配错误提示列出所有收取者；按订单5/3分装时明确不要求一样多。
- 翻牌卡背隐藏整个答案子树，覆盖旧样式强制显示嵌套图片的问题。已配对的答案正常揭示。
- 颜色图形此前只有边框，没有宽高，退化成小点。英语图片卡显式设置图形尺寸：普通卡桌面最大104像素、手机至少64像素；配对卡在手机上使用54像素图形。
- 5岁第2关《谁藏在谜语里》增加已有片库中的 *Our Listening Ears*（Super Simple Songs，`uBweptmCYZg`）：用声音线索猜动物，作为推理与倾听拓展，不代替中文谜语教学。5岁第3关沿用 *Shapes I See At The Beach*。
- 有配片的短片环节直接显示“看动画短片 / 看原创演示”，切换后记住偏好，不必进入家长菜单。其余未配适合原片的新增课程仍使用原创演示。本次验证入口、正确嵌入地址及记忆，不代表所有网络环境均可起播。
- 声音配对选中后加深颜色、显示“正在听”；错选保留选中声音和既有连线。配对后两端显示同色边框、对应编号与连线，可以再次听声音。全部配对后保留关系图，孩子点击继续；缩放及刷新恢复后重新计算连线。
