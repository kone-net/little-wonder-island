# 小小奇遇岛 · Little Wonder Island

每天一个小冒险，玩出一个新发现。

V2 · 可部署课堂

本目录是完整的静态网站，入口为 `index.html`。包含 3、4、5、6 岁四档各十节、共四十节课程，八环节课堂、多种主题互动、原创 SVG 故事动画、本地中英文配音、离屏任务和家长观察记录。

## 视频资源

40 个关卡各配一集不同视频，来源包含 Super Simple、Sesame Street、Bluey、MiniKoVerse、Finny、Noodle & Pals、Tuk Tuk Draw 等；补充 Scratch Garden 和 Jack Hartmann。Numberblocks 本次测到的条目嵌入受限，保留原片资料，课堂采用可播替代。

打开 `video-library.html` 搜索 540 条短视频记录：40 条已配课，500 条仅经元数据初筛、需要逐片复核。DG Slow English 长片作为单独拓展，不进入低龄默认课堂。`assets/video-library.js` 保存机器可读元数据和逐关映射；候选不表示已经完整审看或全球可播。

## 发布

将 **code 目录内的全部内容** 上传到任意支持静态文件的网站空间，保持 `assets` 目录结构。可以部署在域名根目录或子目录，不需要修改基础路径。

无需 Node、Python、模型、数据库、API 密钥或账号服务。原创课堂和配音可独立使用；每关预选一集官方视频，点击播放后才加载 YouTube 嵌入。视频需联网，可能受广告、地区、登录验证或嵌入限制影响，可随时切回原创故事。所有自产配音随网站提供。正式环境使用 HTTPS，服务器正确提供 HTML、JavaScript、CSS、SVG、JSON、MP3 的 MIME 类型；MP3 建议支持字节范围请求。

资源文件使用内容哈希命名。更新时同步上传页面、脚本、音频清单和所有新音频，避免只替换清单。HTML 和清单建议及时重新验证缓存。

## 本地预览

在项目根目录执行：

```powershell
node release/v2/test/serve.js
```

默认入口：`http://127.0.0.1:52378/`。可用环境变量 `PORT` 修改端口。

直接打开 `index.html` 也能读取课程；日常体验和验证建议使用 HTTP，浏览器对本地文件的声音和存储权限可能不同。

## 使用

- 首次选择年龄并记住选择。每个年龄都有自己的第 1–10 关和续关位置，顶部可更换年龄，各年龄的操作和观察互相保留。首页默认按当前年龄第 1–10 关顺序冒险。点击大按钮直接开始或接着上次的课程、环节和操作状态，不必每次选课；材料显示在按钮旁。
- 完成一课后，结局页突出下一关，也可先休息。全部走完后提供回顾，保留已有记录。“看看全部关卡 · 家长选课”是折叠的次要入口，自由浏览不会改变续关位置，实际开始另一课才会切换。
- 原有 V2 的 01–10 课程与进度自动归入四岁并接入，优先恢复最近实际使用的未完成课程；之后记住续关位置。环节导航可回看，不把答题作为解锁故事的条件。
- 中文沿用候选 3 的已确认连续开场参考，使用 CosyVoice3 zero-shot 上下文。英语为 Kokoro `af_heart`，基础速度 0.78，可额外慢放。
- 浏览器首次播放声音需要点击页面。没有声音时点击“再听一遍”；可关闭声音配合字幕观看。
- 页面切到后台会暂停。休息面板能继续或保存回首页。普通、悬停和键盘聚焦状态均有清晰按钮。
- 约二十分钟是活动预算，不强制等满；实际用时会随材料操作、讨论、回看和孩子节奏变化。
- 进度和观察使用当前站点的 localStorage。发布到新域名、换浏览器或设备，不会自动迁移旧设备记录。可在家长记录中导出 JSON 留存；本版没有云端账号和同步。
- “试过了”由陪伴者确认，不是摄像头、语音识别或能力测评。实物材料没备好时会记作稍后再试。

## 文件

- `index.html`：网站入口。
- `assets/app.js`、`app.css`：课堂流程、声音、暂停与进度。
- `assets/game-engine.js`：各主题任务与判定。
- `assets/interaction-motion.js`：跟手拖动、目标高亮、落盘过渡和无效拖放回弹；点击和键盘放置也有过渡，遵循系统减少动态效果设置。
- `assets/characters.js`、`scenes.js`、`scene.css`：角色、场景及动画。
- `assets/lessons.js`：四十节课程台词、分镜、分龄时间预算和活动内容。
- `assets/audio.js`、`audio-zh.json`、`audio-en.json`：发布音频索引及生成记录。
- `assets/audio/`：最终 MP3。

测试、配音生成工具、WAV 母版和日志位于上一级 `test`，不需要上传。教案和合订本保留在上一级，课堂运行不读取这些文档。

故事自动播放在旁白结束后约 0.45 秒接下一段，并提前加载下一段音频；实际衔接还受设备和网络影响。最后一幕明确停在结尾，声音加载失败时保留字幕并等待重试，不在长时间静默后跳到下一幕。

## 概念与英语

40 节课都提供“概念名称、具体解释、具体例子、操作任务”的对应关系，并有固定参考音色的概念讲解。各轮游戏单独标出方法；二等分、三等分、四等分都要求各份一样多，按不同订单分装单独命名。

三岁英语预算约四分钟，四到六岁约五分钟，总预算仍为二十分钟。每课十二步，词语和句子在示范中默认各读三遍，词物同步突出显示；听辨时取消答案提示，并通过换位置、换背景配色、指实物与轮流表达迁移。可重听、慢放、只听或提前继续。记录陪伴者确认的尝试，不采集录音，不做自动发音评分。

外部儿歌观看由陪伴者确认，和本地六幕观看记录分别保存，不将打开播放器当作看完。

通过 `file://` 双击本地课堂时，儿歌按钮会打开线上 `watch.html` 播放页；本地文件无法提供 YouTube 要求的 HTTP Referer，直接嵌入会报 153。HTTP/HTTPS 课堂使用实际网站 origin 与 `strict-origin-when-cross-origin` 来源策略；播放器新窗口链接保留来源信息。在线播放页不会读取或迁移本地课堂的学习记录，原课堂保留在原标签页。
