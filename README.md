# 小小奇遇岛 · Little Wonder Island

V2.6.2 统一交互版：3—12岁，每龄20关，共200关。

英语单词和句子附中文释义；新增课的原创短片使用独立三段图解，第14关纸龙舟使用专属动画，短片不再显示画板和游戏编辑器。

修正分龄教学与翻牌遮挡，放大英语图形，补充5岁第2关动画入口；声音配对支持选中反馈、连线和完成后查看。详见 [修正记录](docs/CONTENT-FIXES-20261026.md)。

打开 index.html，选择年龄后按顺序续关。所有课程进入 classroom.html，共用固定五个可跳转环节。旧链接自动映射，原学习记录与已完成课程保留。games.html 展示每关具体任务及英语游戏安排。

故事和讲解连续播放；游戏保留实际操作，错误可调整并查看示范，完成后自动反馈。创作、口述和真实活动以参与记录为准，不自动判优劣。原规则引擎继续校验数学、棋类、程序和实验任务。

英语示范两遍，包含物品联动、听辨、记忆、投递、配对、宾果、排序、路线和情境表达。可自愿录音、听回放并获得鼓励，也可先听并继续；不做发音评分。录音最长六秒，只在内存中暂存，暂停和离开即关闭采集，不上传原音。

原1014段Cherry中文和787段Heart英语文件不变，另附样板及通用英语指令、鼓励语。视频偏好在同一浏览器记住；无适配原片的课使用原创方法演示，不循环凑时长。20分钟为活动预算，不是20分钟连续配音。

把本目录完整上传到HTTPS静态站点即可发布，不需要Node、Python、模型、密钥或数据库。录音需要支持MediaRecorder的浏览器和用户主动授予的麦克风权限；不支持或拒绝权限也能继续。学习记录保存在当前浏览器，可从首页家长记录导出导入，跨来源和设备不自动同步。

实现和验收范围见 docs/UNIFIED-CLASSROOM.md。构建、测试、模型和WAV母版位于release/v2/test，不随静态站点部署。
