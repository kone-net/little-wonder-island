# 小小奇遇岛 · Little Wonder Island

V2.5：3—12岁，每龄20关，共200关。每天一个小冒险，玩出一个新发现。

## 使用

打开 `index.html`，选年龄后顺序续关。家长可展开目录按主题或科目回看；各龄独立保存。旧链接继续兼容，`classic.html` 保留原四十课内容与互动，并采用当前统一配音。新路径能读取旧进度并在完成旧课后回到二百关路径。

十二类互动覆盖语数外、艺术、科学、生活、体育和棋类：包括真实可连接的低压电路模型、可撤销画板、顺序与分类、数量模型、路线程序、节奏及规则验证的棋局。棋类为分龄规则练习、小残局与家庭轮流游戏，不是完整象棋AI。作品、写话和运动采用参与确认，不自动判断内容质量。

新增160课每课提供具体任务、三幕原创方法演示、英语、离屏迁移和回顾。20分钟是活动预算，不是20分钟连续配音。原四十课保留较丰富的旧课堂与官方配片入口。

## 声音与视频

1801段本地音频：中文1014段使用IndexTTS-2.5 Cherry参考复刻，英语787段保留原Kokoro Heart 0.78文件不变。支持三遍示范、物品联动、听辨和仅英语额外0.85倍慢放。模型、参考和WAV不随站点分发。

视频素材页 `video-library.html` 有540条短视频记录，含40条原配片与500条待逐片复核的候选。受限原片与DG Slow English长片分开记录。新增课的原创方法短片显示实际时长，并非200集商业动画。外部视频点击后才联网；本地file来源通过HTTPS watch页打开外部视频。

## 部署

把本目录全部内容上传到静态HTTPS站点，不需要Node、Python、密钥、账号或数据库。支持根目录与子路径。保持相对资源路径，提供正确MIME与MP3字节范围。

学习记录保存在浏览器本机，可在家长记录导出导入；绘画也可下载PNG。不同来源、浏览器和设备不自动同步。未启用麦克风、摄像头或作品公开上传。
